Nosso Diferencial

Desenvolver uma dashboard interativa personalizada para monitoramento climático com sugestões de atividades e um avatar animado.

Por que uma Dashboard?

O BreathFree surge como uma solução inovadora para monitoramento climático, destacando-se das tradicionais previsões do tempo ao integrar dados ambientais com sugestões práticas de atividades. Com o uso de uma dashboard personalizada e um avatar interativo, buscamos promover o bem-estar do usuário com base no impacto climático diário.

  • Implementar integração com APIs de dados meteorológicos.
  • Criar um sistema de autenticação e personalização do perfil do usuário.
  • Desenvolver um avatar interativo que realiza atividades baseadas nas condições climáticas.

Vantagens da Dashboard

1. Tomada de decisão mais rápida

Experiência personalizada

Visualização clara

Como funciona nossa Dashboard

🌬️ BreathFree — O clima que entende você A BreathFree é uma dashboard interativa que transforma dados climáticos em ações personalizadas. Desenvolvida em Java e integrada com APIs em tempo real, ela adapta a interface conforme o perfil do usuário. 💡 Exibe apenas o que importa: clima, saúde e sugestões práticas — sempre com um avatar animado representando o “mood do dia”. Mais que previsão do tempo, a BreathFree te guia com inteligência e empatia. ⚙️🌤️

  • Dados em tempo real
  • Gráficos e históricos acessíveis em nosso dashboard
  • Alertas de eventos extremos
